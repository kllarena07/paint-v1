# Automated Voting System

Automates voting on PaintAStreet.com with cookie rotation to minimize downtime and handle rate limits.

## Background

This tool works by navigating the [Token Bucket](https://www.geeksforgeeks.org/computer-networks/token-bucket-algorithm/) algorithm employed by Paint a Street. The site enforces a rate limit of 10 votes per 10-minute window, after which the quota is fully reset.

Validation is handled via session cookies generated by Cloudflare Turnstile. By collecting an arbitrary list of these tokens, we can maintain a steady rate of one vote every two seconds, ensuring we don't trigger additional request rate limiting. See below for how to obtain these.

## How to Get Tokens

<https://github.com/user-attachments/assets/64c208f0-b2af-4ad4-8602-19c8a68aa55d>

1. Open up <https://paintastreet.com/>
2. F12/Inspect and navigate to "Application"
3. Navigate to "Storage", check "Including third-party cookies", and hit "Clear site data" (this is to ensure that we have a fresh Cloudflare Turnstile token)
4. Navigate to "Network" and filter the search for "vote" (we're looking for invocations on the `/vote` endpoint)
5. Initiate the CF Turnstile process by clicking on any tile and hit "downvote"
6. Observe the "Network" tab for any `/vote` invocations and look for the `Cookie` request header. Take the RNGed value after the `session=` part of the header and insert it into `valid_cookies.txt` as a new line.
7. Repeat this process N amount of times, storing each new token in `valid_cookies.txt` in your root directory.

## Setup

### Prerequisites

Install Docker and Docker Compose on your system:

- [Docker Desktop](https://www.docker.com/products/docker-desktop) (Mac/Windows)
- [Docker Engine](https://docs.docker.com/engine/install/) (Linux)

### Prepare Cookies File

Create a file named `valid_cookies.txt` in the project root:

- Add valid PaintAStreet.com session cookies, one per line
- Each line should contain only the session cookie value (not the full cookie string)
- Example content of `valid_cookies.txt`:

  ```
  your_cookie_value_1_here
  your_cookie_value_2_here
  your_cookie_value_3_here
  ```

## Usage

### Start the System

Run the voting system in the background:

```bash
docker-compose up -d
```

### Monitor Logs

View real-time logs from the voting container:

```bash
docker-compose logs -f voter
```

### Check Status

See if the container is running:

```bash
docker-compose ps
```

### Stop the System

Gracefully stop the container:

```bash
docker-compose down
```

### Restart

Restart the voting system:

```bash
docker-compose restart
```

## Architecture

```
Main Loop (1 vote/2 seconds)
    ↓
Check cookie usage (< 10 votes?)
    ↓ Yes
Cast vote with current cookie
    ↓
Log success/error
    ↓
Wait for next interval

If cookie usage >= 10:
    ↓
Rotate to next cookie in valid_cookies.txt
    ↓
Reset vote count for new cookie
    ↓
Return to main loop
```

## Troubleshooting

**Container Not Starting**:

- Check if Docker daemon is running: `docker ps`
- View container logs: `docker-compose logs voter`
- Ensure `valid_cookies.txt` exists and is readable

**Cookie File Not Found**:

- Ensure `valid_cookies.txt` exists in the project root
- Verify Docker volume mount is correct in `docker-compose.yml`
- Check file permissions: `ls -la valid_cookies.txt`

**No Valid Cookies**:

- Make sure `valid_cookies.txt` contains valid session cookies
- Each line should have one cookie value
- Remove empty lines and whitespace
- Check logs: `docker-compose logs voter`

**Permission Denied on Cookies File**:

- Fix file permissions: `chmod 644 valid_cookies.txt`
- Ensure the file is not owned exclusively by another user

**Rate Limit Errors**:

- Normal behavior - system will automatically rotate cookies
- Check statistics output for total errors
- If all cookies are exhausted, the container will stop

**Network Errors**:

- Check internet connection
- Verify PaintAStreet.com is accessible
- Check firewall settings and Docker network configuration

**Cookie Exhaustion**:

- All cookies have been used and rate limited
- Update `valid_cookies.txt` with new valid session cookies
- Restart container: `docker-compose restart`

## Stopping

Stop the container gracefully:

```bash
docker-compose down
```

The system will display final statistics in the logs before shutting down. View the final logs:

```bash
docker-compose logs voter
```
